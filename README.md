# Student Management System

This project is a very simple student management system made with basic Object-Oriented Programming (OOP).

## What this project does
- Creates students
- Creates courses
- Adds students to a school
- Adds courses to a school
- Enrols students in a course
- Removes a student from a course
- Displays the courses and students

## Basic OOP used
This project uses only simple beginner-friendly OOP ideas:
- Classes
- Constructors
- Functions
- Variables

## Main classes
### Student
Stores:
- student name
- student ID
- enrolment status

### Course
Stores:
- course name
- a list of students in that course

### School
Stores:
- a list of students
- a list of courses

Also contains actions such as:
- add_student()
- add_course()
- enrol_student()
- remove_student()
- display_courses()

## How to run
Open the file in Python and run it.

Example:
```python
python student_management.py
```

## Simple explanation
The School class manages everything. Each student is created from the Student class, and each course is created from the Course class.

This is a beginner project to practice:
- classes
- objects
- methods
- lists
- simple logic

## Notes
This project is intentionally simple and easy to understand for a beginner certification level.
